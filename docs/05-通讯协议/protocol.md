# 通信协议 — 已废弃

> **当前项目已不再使用此协议。** N6 单板方案中，检测和控制都在同一块 OpenMV N6 上完成，无外部通信。
>
> 此协议适用于旧架构 (OpenMV4 H7 Plus → UART → STM32F103C8T6)，保留作为历史参考。

---

## 物理层 (旧)

| 参数 | 值 |
|------|------|
| 串口 | USART3 |
| 引脚 | OpenMV TX(P4) → STM32 PB11(RX), GND ↔ GND |
| 波特率 | 115200 8N1 |

## 帧格式 (旧, 5 字节)

```
[0xFF] [0xFE] [hasBlob] [tx] [ty]
```

- `hasBlob`: 0x01=检测到, 0x00=丢失
- `tx/ty`: 归一化 0-255, 128=中心 (QVGA 320×240)
