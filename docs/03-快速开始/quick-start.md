# 快速开始

本指南帮助你在最短时间内完成二自由度云台的开箱检查、组装、驱动安装、固件烧录和运行验证。

## 1. 开箱检查

### 1.1 包装清单

收到云台后，请先确认所有配件完整。标准配置包含以下组件：

| 配件 | 数量 | 说明 |
|------|------|------|
| C06主控板 | 1块 | 基于STM32F103C8T6 |
| 底舵机 | 1个 | 水平旋转舵机 |
| 摇臂舵机 | 1个 | 俯仰控制舵机 |
| USB数据线 | 1条 | 用于程序下载 |
| 配件包 | 1袋 | 螺丝、螺母、支架等 |

### 1.2 检查要点

1. 确认主控板外观无损坏，焊点完整
2. 检查舵机线缆连接是否牢固
3. 确认所有螺丝和支架配件齐全
4. 如有缺失，请及时联系供应商

## 2. 硬件组装

### 2.1 组装顺序

1. **安装底舵机**：将底舵机固定在底座上
2. **安装主控板**：将C06主控板固定在底舵机上方
3. **安装摇臂舵机**：将摇臂舵机固定在主控板支架上
4. **连接舵机线**：将舵机信号线连接至主控板对应接口

### 2.2 接线说明

**底舵机接线**（使用S1接口）：
- 红线：5V电源正极
- 黑线：GND电源负极
- 黄线：PWM控制信号

**摇臂舵机接线**（使用S2接口）：
- 红线：5V电源正极
- 黑线：GND电源负极
- 黄线：PWM控制信号

**PS2手柄**（可选）：连接至主控板PS2接口

### 2.3 360度版本特殊注意

如果使用的是360度底舵机版本，必须在主控板上连接跳线帽，否则舵机无法正常工作。跳线帽位置详见《二自由度云台开发手册》第3.1章。

## 3. 选择源码版本

根据你的云台配置（底舵机和摇臂舵机的角度），选择对应的源码版本：

### 3.1 源码版本对照表

| 序号 | 底舵机 | 摇臂舵机 | 库类型 | 适用场景 |
|------|--------|----------|--------|----------|
| 0 | 270度 | 270度 | 标准库 | 常规使用 |
| 1 | 270度 | 180度 | 标准库 | 常规使用 |
| 2 | 270度 | 270度 | 标准库 | 常规使用（备用） |
| 3 | 270度 | 180度 | HAL库 | 喜欢HAL库开发 |
| 4 | 270度 | 270度 | HAL库 | 喜欢HAL库开发 |
| 5 | 360度 | 180度 | 标准库 | 连续旋转底座 |
| 6 | 360度 | 270度 | 标准库 | 连续旋转底座 |
| 7 | 360度 | 180度 | HAL库 | 连续旋转底座 |
| 8 | 360度 | 270度 | HAL库 | 连续旋转底座 |

### 3.2 快速选择

根据常见配置选择：

- **270度底舵 + 270度摇臂** → 源码 0 或 2 或 4
- **270度底舵 + 180度摇臂** → 源码 1 或 3
- **360度底舵 + 180度摇臂** → 源码 5 或 7
- **360度底舵 + 270度摇臂** → 源码 6 或 8

### 3.3 HAL库 vs 标准库

- **标准库版本**（0、1、2、5、6）：适合熟悉STM32标准库开发的用户
- **HAL库版本**（3、4、7、8）：适合喜欢HAL库抽象层的用户

### 3.4 360度版本限制

使用360度底舵机的版本有以下限制：
- 仅支持PS2遥控控制
- 不支持串口控制、ROS例程、Python例程
- 360度舵机为开环速度控制，无角度反馈

## 4. 安装驱动

### 4.1 CH9102驱动安装

C06主控板使用CH9102芯片实现USB转串口功能，需要安装驱动程序。

**驱动位置**：
```
WHEELTEC_二自由度云台资料包（C06主控版-当前版本）\
2.使用教程与开发手册\
C06B主板外设资源教程视频\
1. USB一键下载\
CH9102驱动与资料\
CH343SER（CH9102的windows驱动）.ZIP
```

**安装步骤**：
1. 解压驱动压缩包
2. 双击`Driver`文件夹中的`SETUP.EXE`
3. 按照提示完成驱动安装

### 4.2 验证驱动安装

1. 使用USB线连接主控板的USB接口到电脑
2. 打开Windows设备管理器
3. 在"端口（COM和LPT）"下查看是否有"USB-Enhanced-SERIAL CH9102"设备
4. 记住对应的COM端口号（如COM3、COM4等）

## 5. 烧录固件

### 5.1 获取烧录工具和固件

**FlyMcu软件位置**：
```
WHEELTEC_二自由度云台资料包（C06主控版-当前版本）\
2.使用教程与开发手册\
C06B主板外设资源教程视频\
1. USB一键下载\
FlyMcu.exe
```

**固件文件**（hex文件）在各版本源码包中，解压后可在`hex`或`output`目录下找到。

### 5.2 烧录步骤

1. 打开FlyMcu软件
2. 在"串口"下拉框中选择对应的COM端口
3. 设置波特率为**115200**
4. 点击"搜索串口"确认连接正常
5. 点击"读取器件信息"验证芯片识别
6. 在"文件"栏中选择要烧录的hex文件
7. 点击"开始编程"按钮
8. 等待烧录完成（进度条走完）

### 5.3 烧录配置

| 配置项 | 建议值 |
|--------|--------|
| 波特率 | 115200 |
| 编程地址 | 0x08000000 |
| 擦除 | 需要 |
| 校验 | 不需要 |

### 5.4 常见问题

- **找不到串口**：检查CH9102驱动是否正确安装
- **下载失败**：尝试降低波特率至9600，或手动点击"复位芯片"后重试
- **提示无法连接**：确认USB线是数据线（不是仅充电线）

## 6. 首次运行验证

### 6.1 通电前检查

1. 确认所有接线正确牢固
2. 确认供电电压在7-12V DC范围内
3. 确认源码版本与云台配置匹配

### 6.2 通电测试

1. 连接电源（7-12V直流适配器）
2. 观察主控板LED指示灯是否亮起
3. 观察OLED屏幕是否有显示

### 6.3 控制方式

**PS2手柄控制**（默认）：
- 左侧摇杆：控制底舵机（左/右旋转）
- 右侧摇杆：控制摇臂舵机（上/下俯仰）

**串口控制**（270度版本可用）：
通过串口发送指令控制云台角度。

### 6.4 正常运行状态

- 云台能够响应控制信号动作
- 舵机运行平稳，无异常抖动
- 无异响或异味

### 6.5 异常情况处理

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| LED不亮 | 供电异常 | 检查电源和接线 |
| 舵机不动 | 接线松动/跳线帽未装 | 检查线缆连接（360度版本需装跳线帽） |
| 舵机抖动 | 信号干扰/供电不足 | 检查供电电压和电流 |
| 动作异常 | 源码版本不匹配 | 确认云台配置并选择正确源码 |
