# 工程源码解析

## 1. 概述

本文档对 WHEELTEC 二自由度云台 STM32 控制源码进行全面解析。该工程支持 8 种不同的硬件配置组合，分别针对不同的舵机类型（270°/360°）和开发库（标准库/HAL库）进行了适配。

工程源码位于资料包路径：`1.工程源码/`

## 3. 目录结构

```

├── Core/                    # 核心驱动代码
│   ├── src/                 # 源文件
│   └── inc/                 # 头文件
├── HARDWARE/                # 硬件驱动层
│   ├── PWM/                 # PWM输出驱动

│   ├── KEY/                 # 按键输入
│   └── ...

│   ├── delay/               # 延时函数
```

## 4. 关键源文件说明

### 4.1 主程序入口 (main.c)

主程序负责系统初始化、舵机控制循环以及指令解析。主要流程包括：

- 系统时钟初始化
- GPIO外设初始化
- PWM输出初始化
- 串口通讯初始化
- 舵机控制循环

### 4.2 PWM舵机控制

PWM信号用于控制舵机角度/速度：

- **PWM频率**：通常为50Hz（周期20ms）
- **PWM脉宽范围**：500us-2500us对应舵机角度/速度

### 4.3 串口指令解析

通过串口接收上位机或ROS发送的控制指令，解析后执行对应的舵机动作。

## 5. 舵机控制原理

### 5.1 PWM信号控制

舵机采用PWM信号进行控制：
- PWM周期：20ms（50Hz）
- 脉宽范围：500us-2500us
- 不同脉宽对应不同的角度或速度输出

### 5.2 270°舵机特性

270°舵机为角度控制型舵机：
- 支持精确角度反馈
- 可通过PWM脉宽直接设定目标角度
- 适用于需要精确位置控制的场景

### 5.3 360°舵机特性

360°舵机为速度控制型舵机：
- 无角度反馈功能
- PWM脉宽控制输出轴转速
- 无法直接获取当前位置信息
- 需要通过外部传感器（视觉等）实现闭环角度控制

## 6. 360°舵机特殊处理

### 6.1 控制方式差异

360°舵机的控制相当于直流电机的开环控制：
- PWM脉宽控制的是输出轴的转速，而非位置
- 无法像270°舵机那样直接设定目标角度
- 需要通过外部检测闭环实现角度控制（如视觉检测目标相对位置）

### 6.2 功能限制

由于360°底舵机的特性，以下功能**不支持**：
- 串口角度指令控制
- ROS例程角度控制
- Python例程角度控制

### 6.3 支持的控制方式

360°底舵版本**仅支持PS2遥控器控制**，控制方法与270°底舵版本相同。

### 6.4 下载注意事项

源码下载需要接跳线帽，具体操作请查看《二自由度云台开发手册》第3.1章说明。

## 7. 开发库版本说明

### 7.1 标准库版本

标准库版本使用ST的经典标准外设库，适合习惯寄存器操作的开发者，代码直接、可读性好。

### 7.2 HAL库版本

HAL（Hardware Abstraction Layer）库版本提供更抽象的硬件操作接口，适合需要跨平台移植的项目。

## 8. 选型建议

- 只需角度控制：选择270°底舵机 + 270°/180°摇臂舵机配置
- 需要360°旋转：选择360°底舵机配置（仅支持PS2遥控）
- 需要快速开发：选择标准库版本
- 需要跨平台移植：选择HAL库版本
