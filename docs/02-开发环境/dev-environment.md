# 开发环境

## 1. 概述

本文档介绍二自由度云台系统的开发环境搭建，包括USB一键下载（CH9102驱动 + FlyMcu）和ST-Link调试两种程序下载方式，以及Keil MDK工程导入方法。

**主控芯片**：STM32F103C8T6（ARM Cortex-M3，72MHz，64KB Flash，20KB SRAM）

**开发工具**：
- Keil MDK（用于编辑和编译STM32工程）
- FlyMcu（串口下载软件）
- ST-Link（调试器）

**资料包位置**：`WHEELTEC_二自由度云台资料包（C06主控版-当前版本）`

## 2. USB一键下载

USB一键下载方式使用CH9102芯片实现USB转串口功能，通过FlyMcu软件将程序下载到STM32芯片。

### 2.1 CH9102驱动安装

CH9102是USB转串口芯片，需要安装相应的驱动程序才能使用。

**驱动位置**：
```
2.使用教程与开发手册/C06B主板外设资源教程视频/1. USB一键下载/CH9102驱动与资料/CH343SER（CH9102的windows驱动）.ZIP
```

**安装步骤**：
1. 解压驱动压缩包
2. 双击`Driver`文件夹中的`SETUP.EXE`
3. 按照提示完成驱动安装
4. 使用USB线连接主控板的USB接口
5. 在设备管理器中确认串口号（如COM3、COM4等）

**注意事项**：
- 如果需要修改串口号（仅CH9102F支持，CH9102X不支持），可使用CH9102修改串口号工具
- Linux系统驱动安装请参考驱动目录下的`使用说明.txt`

### 2.2 FlyMcu软件使用

FlyMcu是一款常用的STM32串口下载软件，支持一键下载功能。

**软件位置**：
```
2.使用教程与开发手册/C06B主板外设资源教程视频/1. USB一键下载/FlyMcu.exe
```
或
```
7.软件与驱动/STM32F串口下载软件（FLYMCU）/FlyMcu.exe
```

**下载步骤**：
1. 打开FlyMcu软件
2. 选择对应的串口号（连接CH9102后出现的端口）
3. 设置波特率为115200或9600
4. 点击"读取器件信息"确认芯片连接正常
5. 选择要下载的hex文件
6. 点击"开始编程"或"下载"按钮
7. 等待下载完成

**配置说明**：
- 跳到编程地址：0x08000000
- 编程到Flash时一定要擦除
- 不需要校验（选项字节恢复默认）

**一键下载模式**：
主控板支持一键下载功能，无需手动复位芯片。下载时软件会自动控制BOOT引脚电平，实现自动进入编程模式。

## 3. ST-Link调试

ST-Link是STMicroelectronics推出的调试器，支持在线调试和程序下载。

**驱动位置**：
```
2.使用教程与开发手册/C06B主板外设资源教程视频/2. ST-Link下载/STLINK驱动.zip
```

**接线说明**：
| ST-Link引脚 | C06主控板引脚 | 说明 |
|-------------|---------------|------|
| SWCLK | SWCLK | 时钟信号 |
| SWDIO | SWDIO | 数据信号 |
| GND | GND | 公共地 |
| 3.3V | 3.3V | 供电（可选） |

详细接线图请参考：`2.使用教程与开发手册/C06B主板外设资源教程视频/2. ST-Link下载/ST-Link接线.png`

**驱动安装**：
1. 解压STLINK驱动压缩包
2. 安装对应的驱动程序

**Keil MDK中配置ST-Link**：
1. 在Keil中打开工程
2. 点击"Options for Target"（魔术棒图标）
3. 选择"Debug"标签
4. 选择"ST-Link Debugger"
5. 点击"Settings"进入配置
6. 确认SWD模式已选择
7. 点击"OK"保存

**下载步骤**：
1. 连接ST-Link与主控板
2. 在Keil中点击"Load"按钮（或按F8）
3. 等待下载完成
4. 可使用调试功能进行单步调试

| 1.二自由度-底舵机270度摇臂舵机180度_云台STM32源码.zip | 270度 | 180度 | 标准库 |
| 2.二自由度-底舵机270度摇臂舵机270度_云台STM32源码.zip | 270度 | 270度 | 标准库 |

| 4.二自由度-底舵机270度摇臂舵机270度_云台STM32_HAL库版本.zip | 270度 | 270度 | HAL库 |
| 5.二自由度-底舵机360度摇臂舵机180度_云台STM32源码.zip | 360度 | 180度 | 标准库 |
| 6.二自由度-底舵机360度摇臂舵机270度_云台STM32源码.zip | 360度 | 270度 | 标准库 |

**导入步骤**：
1. 解压源码压缩包到不含中文路径的目录
2. 打开Keil MDK软件
3. 点击"Project" -> "Open Project"
4. 浏览到解压目录，选择`.uvproj`或`.uvprojx`工程文件
5. 等待工程加载完成
6. 点击"Rebuild"按钮编译工程

**360度版本注意事项**：
- 360度底舵版本为直流电机式开环控制，无角度反馈
- 仅支持PS2遥控方式控制
- 不支持串口控制、ROS例程、Python例程
- 下载源码时请下载与云台配置对应的版本

## 5. 常见问题

### 5.1 USB下载问题

**问题：FlyMcu找不到串口**
- 解决方法：检查CH9102驱动是否正确安装，确认USB线连接正常

**问题：下载失败**
- 解决方法：
  - 确认串口号选择正确
  - 尝试降低波特率（如从115200降到9600）
  - 点击"复位芯片"按钮手动复位后重试
  - 检查BOOT跳线设置是否正确

**问题：提示"无法连接芯片"**
- 解决方法：
  - 检查USB线是否为数据线（不是仅充电线）
  - 尝试重新安装CH9102驱动
  - 确认主控板供电正常

### 5.2 ST-Link问题

**问题：Keil检测不到ST-Link**
- 解决方法：
  - 检查ST-Link驱动是否安装
  - 确认ST-Link与主控板接线正确
  - 尝试重新插拔ST-Link

**问题：调试时经常断连**
- 解决方法：
  - 检查接线是否松动
  - 确保供电电压稳定
  - 降低SWD时钟频率

### 5.3 工程编译问题

**问题：编译报错"找不到文件"**
- 解决方法：
  - 确认工程路径不包含中文或特殊字符
  - 将工程解压到不含中文的目录

**问题：编译报错"Flash编程失败"**
- 解决方法：
  - 检查芯片型号是否选择正确（STM32F103C8T6）
  - 确认工程配置中的Flash大小设置正确
