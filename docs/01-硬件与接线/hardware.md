# 硬件与接线

## 1. 概述

本文档介绍二自由度云台系统的硬件组成、C06主控板资源、舵机类型及接线方法。云台系统采用C06主控板作为核心控制单元，基于STM32F103C8T6芯片，支持多种舵机配置和外设扩展。

## 2. C06主控板资源

### 2.1 主控芯片

- **芯片型号**：STM32F103C8T6
- **内核**：ARM Cortex-M3
- **主频**：72MHz
- **Flash**：64KB
- **SRAM**：20KB

### 2.2 板载外设

C06主控板集成丰富的外设资源，包括：

| 外设 | 说明 |
|------|------|
| LED | 板载指示灯，用于状态显示 |
| KEY | 板载按键，用于输入控制 |
| BEEP | 蜂鸣器，用于声音提示 |
| OLED | OLED显示屏，用于信息显示 |
| PWM | 舵机控制PWM输出 |
| 蓝牙 | 蓝牙通信接口 |
| CAN | CAN总线通信接口 |
| PS2 | PS2手柄遥控接口 |
| 电阻屏 | 电阻式触摸屏幕接口 |

### 2.3 引脚资源分配

C06主控板关键引脚分配：

- **舵机接口**：5V供电，PWM信号输出
- **串口接口**：用于串口通信调试
- **CAN接口**：用于CAN总线通信
- **蓝牙接口**：用于无线通信
- **PS2接口**：用于PS2手柄连接

## 3. 舵机类型与配置

### 3.1 270度舵机

270度舵机为标准舵机，具有角度反馈功能。

**特性**：
- 角度范围：0-270度
- 控制方式：PWM信号控制
- 角度反馈：可通过PWM信号读取当前位置
- 适用场景：需要精确角度控制的云台

**控制信号**：
- 周期：20ms
- 脉宽范围：0.5ms-2.5ms
- 角度计算公式：`角度 = (脉宽 - 0.5ms) / 2ms * 270度`

**接线方法**：
- 红线：5V电源正极
- 黑线：GND电源负极
- 黄线：PWM控制信号

### 3.2 360度舵机

360度舵机为直流电机式舵机，无角度反馈功能，采用开环速度控制。

**特性**：
- 旋转范围：360度连续旋转
- 控制方式：PWM信号控制转速和方向
- 角度反馈：无（开环控制）
- 适用场景：需要连续旋转的云台底座

**重要说明**：
1. 360度舵机需要连接跳线帽（Boot 模式）才能正常工作，下载固件前请确保跳线帽已连接至正确位置
2. 360度底舵版本为直流电机式开环控制，无角度反馈
3. 实现角度控制需要外部闭环（如视觉检测）配合实现
4. 仅支持PS2遥控方式控制
5. 不支持串口控制、ROS例程、Python例程

**控制信号**：
- 周期：20ms
- 脉宽1.5ms：停止
- 脉宽小于1.5ms：反向旋转（速度与脉宽成正比）
- 脉宽大于1.5ms：正向旋转（速度与脉宽成正比）

## 4. 接线说明

### 4.1 整体接线图

```
+-------------------+
|   C06 主控板      |
|                   |
|  +-----------+    |
|  | 舵机接口   |----+----> 底舵机
|  +-----------+    |
|  | 舵机接口   |----+----> 摇臂舵机
|  +-----------+    |
|                   |
|  +-----------+    |
|  | PS2接口   |----+----> PS2手柄
|  +-----------+    |
|                   |
|  +-----------+    |
|  | 蓝牙接口   |----+----> 蓝牙模块（可选）
|  +-----------+    |
|                   |
+-------------------+
```

### 4.2 舵机接线

**底舵机接线**：
- 使用主控板上的S1舵机接口
- 红线：5V
- 黑线：GND
- 黄线：PWM信号

**摇臂舵机接线**：
- 使用主控板上的S2舵机接口
- 红线：5V
- 黑线：GND
- 黄线：PWM信号

### 4.3 PS2手柄接线

PS2手柄接口位于主控板侧面，连接后即可进行无线遥控操作。

### 4.4 跳线帽连接（360度版本）

**重要**：360度舵机版本必须连接跳线帽，否则舵机无法正常工作。

跳线帽位置及连接方法详见《二自由度云台开发手册》第3.1章。

## 5. 供电要求

### 5.1 供电规格

| 参数 | 规格 |
|------|------|
| 输入电压 | 7-12V DC |
| 舵机供电 | 5V（板载稳压） |
| 最大电流 | 根据负载而定 |

### 5.2 供电注意事项

1. 请使用7-12V直流电源供电
2. 避免使用超过12V的电源，以免损坏主控板
3. 多个舵机同时工作时，注意供电电流是否足够
4. 断电时应先关闭电源，再拆除接线

## 6. 注意事项

### 6.1 通用注意事项

1. 接线时请确保电源关闭
2. 确认接线正确后再通电
3. 避免舵机堵转，以免损坏舵机
4. 定期检查接线是否松动

### 6.2 360度舵机特殊注意事项

1. **必须连接跳线帽**：360度舵机版本需要接跳线帽才能工作
2. **仅支持PS2遥控**：360度底舵版本不支持串口控制、ROS例程、Python例程
3. **开环控制特性**：360度舵机无角度反馈，如需角度控制请通过外部闭环实现
4. **下载源码时注意**：请下载与云台配置对应的源码版本

### 6.3 舵机配置选择

| 配置类型 | 底舵机 | 摇臂舵机 | 控制方式 |
|----------|--------|----------|----------|
| 配置1 | 270度 | 180度 | 串口/PS2/ROS/Python |
| 配置2 | 270度 | 270度 | 串口/PS2/ROS/Python |
| 配置3 | 360度 | 180度 | 仅PS2 |
| 配置4 | 360度 | 270度 | 仅PS2 |

请根据实际购买的云台配置选择对应的源码版本进行开发。
